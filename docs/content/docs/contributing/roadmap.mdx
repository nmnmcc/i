## Field inference

```i error E0506 package=roadmap title="src/main.i"
get = (record) { record.a }
main = () { Nil }
```

```text
E0506
```

**Current limits:** field access needs a known shape; structural inference and width subtyping in [records.md](https://github.com/nmnmcc/i/blob/main/docs/design/records.md) are proposals, while [known gaps](https://github.com/nmnmcc/i/blob/main/docs/design/spec-known-gaps.md) track other type limitations.

The checker uses `Head::Shape`; the proposed `Head::Record`, `Ty::Rec`, and `Ty::Without` variants are absent.

## Extra fields

## Current library

```i run package=roadmap title="src/main.i"
(
	i/core
	i/fail
	(Io) = i/io
	std/json
	std/time
)
main = () <- (io : Io) {
	io.print(
		core.inspect(fail.catch(() { json.parse("oops") })),
	)
	io.print(
		core.inspect(fail.catch(() { time.divide(time.seconds(1), 0) })),
	)
}
```

```text
Error(JsonError(0, "expected value"))
Error(DivisionByZero)
```

`json.parse` and `time.divide` raise errors through `Fail`; `fail.catch` makes them values. [std-v3.md](https://github.com/nmnmcc/i/blob/main/docs/design/std-v3.md) remains partly a plan: JSON has separate `pretty`, and time lacks the proposed high-level `Clock`.

## Current limitations

### Keyed data patterns

Keyed data patterns are not available yet; use field access (DOC1).

### Data-rest patterns

Data-rest patterns are not available yet; list rest patterns work (P13).

### Labelled value printing

`core.inspect` omits field labels when printing labelled values, including errors (DOC2).

### Resource scopes

`resource.scoped` and `Scope` are not available yet; use `resource.acquire` callbacks (EF11).

### Loader generation

The `js` and `nodejs` targets produce Wasm and a binding plan, without generated loaders or declarations; load them through the host SDK (DOC3). The built-in `@js` declaration is not available yet.

### Captured scopes

A scope retained through user suspension can remain usable outside its body and later deadlock (C03).

### Callback environments

Captured callbacks retain unnecessary services, which can prevent portable use (C04).

### Macro budgets

Macro work and frame limits are measured differently from the standard (MP08).

## Available features

| Area | Available today |
| --- | --- |
| Source | Names without keywords, literals, interpolation, line rule. |
| Packages | Imports, exports, manifests, dependencies, locks, configured entries. |
| Types | Inference, labelled types, aliases, literal types, unions, intersections, differences, closed shapes. |
| Expressions | Immutable bindings, functions, branches, guards, matching, fields, spreads. |
| Bits | Construction/matching with integer, float, byte, UTF encodings. |
| Services | Needs/provision, typed failure, continuations, structured tasks, host IO. |
| Execution | Entries, tests, host calls, tail calls, stops, inspection. |
| Macros | Core operations, syntax/typed macros, alternate surface. |

Other exceptions, including a checked program that traps, are recorded in the [gap register](https://github.com/nmnmcc/i/blob/main/docs/design/spec-known-gaps.md). [Open work](/docs/contributing#open-work) lists tasks; [the standard](/docs/standard) defines intended behavior.

## Tools

| Commands | Purpose |
| --- | --- |
| `expand`, `check` | Expanded source; package diagnostics. |
| `build`, `run`, `test` | Artifacts; entry execution; filtered tests. |
| `collections`, `run-collection` | JSON contributions; execute one handle. |
| `new` | Starter program and test. |
| `add`, `remove` | Dependencies and lock updates. |
| `update` | Dependency versions within the current major. |
| `publish` | Package check and local version tag. |
| `deps`, `cache` | Dependency capabilities; cache inspection/trimming. |
| `spec`, `lsp` | Standard lookup; server on standard input/output. |
| `fmt`, `help` | Formatting/surface conversion; command help. |

[CLI commands](/docs/guides/cli) gives usage; each command has help.

`i build` targets are `native` (default; one executable, statically linked on Linux), `host` (alias `ilang`), `js`, `nodejs`, and `wasi` (Wasm modules). Browser/Node targets have [loader generation limits](#loader-generation).

[VS Code](https://github.com/nmnmcc/i/blob/main/editors/vscode/README.md), [Zed](https://github.com/nmnmcc/i/blob/main/editors/zed/README.md), and [tree-sitter](https://github.com/nmnmcc/i/blob/main/editors/tree-sitter-i/README.md) sources provide editor support; the server supplies diagnostics, hover, navigation, completion, and formatting.

## Compiler trees

[ast-hir-merge.md](https://github.com/nmnmcc/i/blob/main/docs/design/ast-hir-merge.md) discusses the tree rewrite. Today's [syntax entry point](https://github.com/nmnmcc/i/blob/main/crates/ilang-syntax/src/lib.rs) returns the current `ast::Module` directly, with transition facts; the old syntax-tree conversion described by earlier reports is gone. Notes give no delivery-date promise.
