Check a design claim against a small program and the current sources.

```i run package=notes title="src/main.i"
(
	i/core
	(Io) = i/io
)

main = () <- (io : Io) {
	record = (a = 1)
	io.print(core.inspect(record.a))
}
```

```text
1
```

[records.md](https://github.com/nmnmcc/i/blob/main/docs/design/records.md) proposes more than the available closed data shapes. A note's opening status can describe an older tree; use the [standard](/docs/standard) for the intended behavior and the compiler for what works today.
