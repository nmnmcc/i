Turn a small behavior into a regression test, then change its implementation.

```i test stdout=exact package=contributing title="test/regression_test.i"
(
	testlib = (test) = i/test
	i/bool
)

test("a regression", () { assert(bool.not(True()) == False()) })
```

```text
pass contributing/regression_test.a regression
1 passed, 0 failed
```

For this change, the source is [stdlib/src/bool.i](https://github.com/nmnmcc/i/blob/main/stdlib/src/bool.i) and neighboring tests live in [stdlib/test/bool_test.i](https://github.com/nmnmcc/i/blob/main/stdlib/test/bool_test.i). For language behavior, begin with the relevant [standard](/docs/standard) text, then a case under `tests/spec`.

## Sources

[Repository layout](/docs/contributing/repository-layout) locates files; [compiler architecture](/docs/contributing/compiler-architecture) traces their connections. [Building and testing](/docs/contributing/building-and-testing) supplies focused commands, and [sending changes](/docs/contributing/how-to-send-changes) gives a worked case.

The project favors a small language, immutable values and bindings, structured task lifetimes, and ordinary library features for services and tests; simplicity precedes optimization. Its goal is a complete standalone language and useful library, without checker-accepted invalid programs trapping at runtime.

**Current limits:** that safety goal is not yet met; T8/F2 records a checked program that traps, alongside other [known gaps](https://github.com/nmnmcc/i/blob/main/docs/design/spec-known-gaps.md); a specified stop is a separate outcome.

## Open work

| Services | EF10: row projection; EF11: resource scope lifecycle and API. |
