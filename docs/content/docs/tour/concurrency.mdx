---
title: Concurrency
description: Start structured tasks, join their results, and handle child failure and cancellation.
---

Run computations alongside each other and wait for their results and cleanup.

```i run package=tour title="src/main.i"
(
	i/task
	i/core
	(Io) = i/io
)
main = () <- (io : Io) {
	answer = task.scope((s) {
		first = task.go(s, () { 20 })
		second = task.go(s, () { 22 })
		task.join(first) + task.join(second)
	})
	io.print(core.inspect(answer))
}
```

```text
42
```

The entry provides the scheduler; tasks use library services and control operations. `Task(A, E)` carries a result and an error type; joining returns `A` or raises through `Fail(E)`.

## Scope lifetime

```i run package=tour title="src/main.i"
(
	i/task
	(Io) = i/io
)
main = () <- (io : Io) {
	task.scope((s) {
		task.go(s, () { io.print("child") })
		Nil
	})
	io.print("scope finished")
}
```

```text
child
scope finished
```

Keep task handles inside their owning scope: returning one does not extend its lifetime. There is no public detached-task operation.

## A pair

```i run package=tour title="src/main.i"
(
	i/task
	i/core
	(Io) = i/io
)
main = () <- (io : Io) {
	io.print(core.inspect(task.both(() { 7 }, () { "eight" })))
}
```

```text
(7, "eight")
```

## An ordered list

```i run package=tour title="src/main.i"
(
	i/task
	i/core
	(Io) = i/io
)
main = () <- (io : Io) {
	values = task.map_concurrently([3, 1, 2], (n) { n * 10 })
	io.print(core.inspect(values))
}
```

```text
[30, 10, 20]
```

Scheduling and completion order can change; prints inside children can interleave. The host chooses workers, whose identity stays hidden; task steps behave as some serial order. Ordinary scopes require portable results and errors (copyable across workers); `task.local_scope` keeps nonportable values on one worker.

## A channel

```i run package=tour title="src/main.i"
(
	i/task
	i/core
	(Io) = i/io
)
main = () <- (io : Io) {
	answer = task.scope((s) {
		channel : task.Channel(Int) = task.channel()
		task.go(s, () { task.send(channel, 42) })
		task.receive(channel)
	})
	io.print(core.inspect(answer))
}
```

```text
42
```

Channels are unbuffered: sending and receiving wait for each other.

## A child error

```i run package=tour title="src/main.i"
(
	i/task
	i/fail
	i/core
	(Io) = i/io
)
main = () <- (io : Io) {
	answer = fail.catch(() {
		task.scope((s) {
			task.go(s, () { fail.raise("child failed") })
			Nil
		})
	})
	io.print(core.inspect(answer))
}
```

```text
Error("child failed")
```

A body or child error cancels the scope’s other work, even without a join. If several fail, the scope chooses one error; cancellation itself is not a failure.

## Cancellation cleanup

```i run package=tour title="src/main.i"
(
	i/task
	i/resource
	i/fail
	i/core
	(Io) = i/io
)
main = () <- (io : Io) {
	answer = fail.catch(() {
		task.scope((s) {
			ready : task.Channel(Nil) = task.channel()
			task.go(s, () {
				resource.ensure(
					() {
						task.send(ready, Nil)
						task.sync(task.never())
					},
					() { io.print("release child") },
				)
			})
			task.receive(ready)
			task.go(s, () { fail.raise("child failed") })
			Nil
		})
	})
	io.print(core.inspect(answer))
}
```

```text
release child
Error("child failed")
```

The readiness message ensures the final is installed before failure; `task.never()` is an event that never becomes ready. Cancellation reaches running tasks at scheduler suspensions, drops unstarted bodies, and shields finals already running. A stop bypasses catches and finals.

**Current limits:** avoid retaining a scope through user suspension, which can deadlock, and unnecessary services around child callbacks, which can prevent portability ([C03, C04](https://github.com/nmnmcc/i/blob/main/docs/design/spec-known-gaps.md)).
