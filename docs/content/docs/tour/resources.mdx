---
title: Resources
description: Acquire values and release them after normal returns or errors.
---

Release acquired values after use, including when a computation raises an error.

```i run package=tour title="src/main.i"
(
	i/resource
	(Io) = i/io
)

main = () <- (io : Io) {
	resource.scoped(() {
		name = resource.acquire(
			() { "handle" },
			(name) { io.print("release " <> name) },
		)
		io.print("use " <> name)
	})
}
```

```text
use handle
release handle
```

Strings stand in for handles so these examples need no files. `resource.scoped`
gives its body a `Scope`, and every `resource.acquire` in that body attaches a
release to it. The releases run when the body ends, in reverse order, also by
an error or a cancellation.

## A returned value

```i run package=tour title="src/main.i"
(
	i/resource
	i/core
	(Io) = i/io
)

main = () <- (io : Io) {
	answer = resource.scoped(() {
		resource.acquire(
			() { 40 },
			(_) { io.print("released") },
		) + 2
	})
	io.print(core.inspect(answer))
}
```

```text
released
42
```

## Nested acquisitions

```i run package=tour title="src/main.i"
(
	i/resource
	(Io) = i/io
)

main = () <- (io : Io) {
	resource.scoped(() {
		outer = resource.acquire(
			() {
				io.print("open outer")
				"outer"
			},
			(name) { io.print("close " <> name) },
		)
		inner = resource.acquire(
			() {
				io.print("open inner")
				"inner"
			},
			(name) { io.print("close " <> name) },
		)
		io.print("use " <> outer <> " and " <> inner)
	})
	io.print("done")
}
```

```text
open outer
open inner
use outer and inner
close inner
close outer
done
```

## A final callback

```i run package=tour title="src/main.i"
(
	i/resource
	i/core
	(Io) = i/io
)

main = () <- (io : Io) {
	answer = resource.ensure(() { 42 }, () { io.print("final") })
	io.print(core.inspect(answer))
}
```

```text
final
42
```

A final can use services, but cannot raise an error. `ensure` also runs it when a control escape unwinds the body.

## A failed use

```i run package=tour title="src/main.i"
(
	i/resource
	i/fail
	i/core
	(Io) = i/io
)

main = () <- (io : Io) {
	answer = fail.catch(() {
		resource.ensure(
			() {
				resource.scoped(() {
					name = resource.acquire(
						() {
							io.print("open")
							"handle"
						},
						(name) { io.print("release " <> name) },
					)
					fail.raise("failed")
				})
			},
			() { io.print("final") },
		)
	})
	io.print(core.inspect(answer))
}
```

```text
open
release handle
final
Error("failed")
```

[Task cancellation](/docs/tour/concurrency) also unwinds finals and waits for cleanup; a stop runs none of them.

## A failed acquisition

```i run package=tour title="src/main.i"
(
	i/resource
	i/fail
	i/core
	(Io) = i/io
)

main = () <- (io : Io) {
	answer = fail.catch(() {
		resource.scoped(() {
			name = resource.acquire(
				() -> String { fail.raise("cannot open") },
				(name) { io.print("release " <> name) },
			)
			io.print("use " <> name)
		})
	})
	io.print(core.inspect(answer))
}
```

```text
Error("cannot open")
```

Release is attached only after acquisition succeeds.
