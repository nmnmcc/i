---
title: A tour of the language
description: Learn the language through small programs that you can run in one scratch project.
---

Run small programs and change one piece at a time.

```i run package=tour title="src/main.i"
(
	i/stdio
)

main = () { stdio.print("Hello from the tour!") }
```

```text
Hello from the tour!
```

Install [i](/docs/getting-started/install), then run `i new tour` and `cd tour`; replace `src/main.i` with this program and run `i run`.

Keep this scratch project; each example replaces the whole file.

## A name

```i run package=tour title="src/main.i"
(
	i/stdio
)

main = () {
	name = "Ada"
	stdio.print("Hello, \(name)!")
}
```

```text
Hello, Ada!
```

The import makes `stdio.print` available; `main` is the entry point.

## Inspection

```i run package=tour title="src/main.i"
(
	i/core
	i/stdio
)

main = () {
	name = "Ada"
	stdio.print(name)
	stdio.print(core.inspect(name))
}
```

```text
Ada
"Ada"
```

Use `core.inspect` to turn any value into a string.

## Several lines

```i run package=tour title="src/main.i"
(
	i/core
	i/stdio
)

main = () {
	name = "Ada"
	stdio.print("Hello, \(name)!")
	stdio.print("Your score: \(core.inspect(6 * 7))")
}
```

```text
Hello, Ada!
Your score: 42
```

`i check` checks a program without running it; `i error` examples elsewhere expect a diagnostic instead of successful execution.

## Formatting

```i format package=tour title="src/main.i"
(i/stdio)
main=(){stdio.print("Hello!")}
```

```text
(
	i/stdio
)
main = () { stdio.print("Hello!") }
```

Run `i fmt` to format the current source.

## Inferred types

```i types package=tour title="src/main.i"
greet = (name) { "Hello, \(name)!" }
main = () { greet("Ada") }
```

```text
tour/main.greet : (String) -> String
tour/main.main : () -> String
```

Run `i check --types` to see the checker’s complete listing; the prefix identifies the package, module, and name.
