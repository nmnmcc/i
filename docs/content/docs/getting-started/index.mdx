This section takes you from a source build to a working project and an editor. Follow the pages in order to run a program and its tests.

1. [Install](/docs/getting-started/install) builds the compiler from source.
2. [First program](/docs/getting-started/first-program) creates a package, runs it, and adds a test.
3. [Editor set-up](/docs/getting-started/editor-set-up) describes the VS Code and Zed integrations.

Continue with [the tour](/docs/tour) for the language, or use the [library reference](/docs/library) while writing a program.
