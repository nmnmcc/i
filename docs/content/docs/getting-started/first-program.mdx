Create, run, and test a package.

```sh
i new hello
```

```text
made the package `hello` in `hello`
run it with `i run --project hello`
```

Put `i` on `PATH`. The command creates `i.toml`, `.gitignore`, `src/main.i`, and `test/main_test.i`. `i.toml` depends on the versioned standard library `i`:

```toml
[dependencies]
i = "github.com/nmnmcc/i//stdlib@0.1.0"
```

`i new` writes the newest published version as the minimum. The first check resolves it into the global cache and records the exact version, commit and content hash in `i.lock`; nothing is copied into the project. `i update i` raises the version, and the source is in `stdlib/` of the i repository. The standard library is not part of `i publish`.

`collection = "i/test.tests"` registers this package's tests in the `tests` collection that the library declares in `i/test`.

## Program

```i run package=hello title="src/main.i"
//// Greetings.
(
	(Io) = i/io
)

(
	greeting
)

/// A greeting for a name.
greeting = (who : String) -> String { "Hello, " <> who <> "!" }
main = () <- (io : Io) { io.print(greeting("hello")) }
```

```text
Hello, hello!
```

The generated source is shown with shorter documentation comments. The second parenthesized group exports `greeting` for other modules; `main` is the entry, and `i run` supplies its `Io` service.

```sh
cd hello
i run
```

```text
Hello, hello!
```

## Tests

```i file=src/main.i title="src/main.i"
//// Greetings.
(
	(Io) = i/io
)

(
	greeting
)

/// A greeting for a name.
greeting = (who : String) -> String { "Hello, " <> who <> "!" }
main = () <- (io : Io) { io.print(greeting("world")) }
```

```i test stdout=exact package=hello title="test/main_test.i"
(
	testlib = (test) = i/test
	hello/main
)

test("greets", () { assert(main.greeting("i") == "Hello, i!") })
test("greets the world", () {
	assert(main.greeting("world") == "Hello, world!")
})
```

```text
pass hello/main_test.greets
pass hello/main_test.greets the world
2 passed, 0 failed
```

Replace the generated test file with these two tests.

```sh
i test
```

```text
pass hello/main_test.greets
pass hello/main_test.greets the world
2 passed, 0 failed
```
