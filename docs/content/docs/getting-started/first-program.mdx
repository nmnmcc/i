Create, run, and test a package.

```sh
i new hello
```

```text
made the package `hello` in `hello`
run it with `i run --project hello`
```

Put `i` on `PATH`. The command creates `i.toml`, `.gitignore`, `src/main.i`, `test/main_test.i`, and a copy of the standard library in `stdlib/`; `i.toml` names that copy with `std = { path = "std" }` under `[dependencies]`, so the package needs no other source tree and stays portable when it moves.

## The standard library copy

The copy is 30 files, about 465 KiB: `i/i.toml`, `stdlib/UNICODE-LICENSE`, and the sources under `i/src`. It is an ordinary path dependency, so you can read and change it like your own code.

`.gitignore` lists only `/build/`, so `stdlib/` is committed with the package and shipped by `i publish`. The copy keeps `stdlib/UNICODE-LICENSE` and the copyright and licence notices in its source files; keep them when you redistribute the package.

No command refreshes the copy: `i update` manages versioned dependencies, but `stdlib/` is a plain directory. To move to a newer standard library, make a temporary package with the newer compiler and replace the directory:

```sh
i new refresh --path ../refresh
rm -rf std
cp -a ../refresh/std std
rm -rf ../refresh
i check
```

If the package itself is named `std`, its copy cannot use the dependency key `std`, because a package cannot depend on itself. `i new std` names the key `stdlib`, and code imports the copy as `stdlib/int`.

## Program

```i run package=hello title="src/main.i"
//// Greetings.
(
	(Io) = i/io
)

(
	greeting
)

/// A greeting for a name.
greeting = (who : String) -> String { "Hello, " <> who <> "!" }
main = () <- (io : Io) { io.print(greeting("hello")) }
```

```text
Hello, hello!
```

The generated source is shown with shorter documentation comments. The second parenthesized group exports `greeting` for other modules; `main` is the entry, and `i run` supplies its `Io` service.

```sh
cd hello
i run
```

```text
Hello, hello!
```

## A new greeting

```i run package=hello title="src/main.i"
//// Greetings.
(
	(Io) = i/io

/// A greeting for a name.
```


```sh
i run
```

```text
Hello, world!
```

## Tests

```i file=src/main.i title="src/main.i"
//// Greetings.
(
	(Io) = i/io
)

(
	greeting
)

/// A greeting for a name.
greeting = (who : String) -> String { "Hello, " <> who <> "!" }
main = () <- (io : Io) { io.print(greeting("world")) }
```

```i test stdout=exact package=hello title="test/main_test.i"
(
	testlib = (test) = i/test
	hello/main
)

test("greets", () { assert(main.greeting("i") == "Hello, i!") })
test("greets the world", () {
	assert(main.greeting("world") == "Hello, world!")
})
```

```text
pass hello/main_test.greets
pass hello/main_test.greets the world
2 passed, 0 failed
```

Replace the generated test file with these two tests.

```sh
i test
```

```text
pass hello/main_test.greets
pass hello/main_test.greets the world
2 passed, 0 failed
```
