Create, run, and test a package.

```sh
i new hello
```

```text
made the package `hello` in `hello`
run it with `i run --project hello`
```

Put `i` on `PATH`. The command creates `i.toml`, `.gitignore`, `src/main.i`, and `test/main_test.i`, and nothing else:

```toml title="i.toml"
name = "hello"
[test]
collection = "i/test.tests"
[dependencies]
i = "github.com/nmnmcc/i//stdlib@X.Y.Z"
```

## The standard library

The standard library is the versioned package `i`, in the directory `stdlib` of the language's repository. `i new` names its newest version, `X.Y.Z` above, and copies none of its files into the package. The first command that loads the package gets that version and records it in `i.lock`; commit `i.lock` with the package. `collection = "i/test.tests"` registers the package's tests in the library's test collection, so `i test` finds them.

`i update i` moves the package to the newest version of the library. `i publish` does not carry the library: a published package names its version, and each user gets it from the repository. To read a module, open its source under [stdlib/src](https://github.com/nmnmcc/i/tree/main/stdlib/src) in the repository, or the [library reference](/docs/library).

The name `i` is reserved for the library: `i new i` is rejected. Any other name, `std` included, is an ordinary package name.

## Program

```i run package=hello title="src/main.i"
//// Greetings.
(
	(Io) = i/io
)

(
	greeting
)

/// A greeting for a name.
greeting = (who : String) -> String { "Hello, " <> who <> "!" }
main = () <- (io : Io) { io.print(greeting("hello")) }
```

```text
Hello, hello!
```

The generated source is shown with shorter documentation comments. The second parenthesized group exports `greeting` for other modules; `main` is the entry, and `i run` supplies its `Io` service.

```sh
cd hello
i run
```

```text
Hello, hello!
```

## Tests

```i file=src/main.i title="src/main.i"
//// Greetings.
(
	(Io) = i/io
)

(
	greeting
)

/// A greeting for a name.
greeting = (who : String) -> String { "Hello, " <> who <> "!" }
main = () <- (io : Io) { io.print(greeting("world")) }
```

```i test stdout=exact package=hello title="test/main_test.i"
(
	testlib = (test) = i/test
	hello/main
)

test("greets", () { assert(main.greeting("i") == "Hello, i!") })
test("greets the world", () {
	assert(main.greeting("world") == "Hello, world!")
})
```

```text
pass hello/main_test.greets
pass hello/main_test.greets the world
2 passed, 0 failed
```

Replace the generated test file with these two tests.

```sh
i test
```

```text
pass hello/main_test.greets
pass hello/main_test.greets the world
2 passed, 0 failed
```
