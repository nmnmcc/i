title: Install
description: Build the compiler from source code.
---

Build i from source code. Get the repository and its binaryen submodule first:

```sh
git clone https://github.com/nmnmcc/i
cd i
git submodule update --init crates/ilang-binaryen/binaryen
```

Install [Nix](https://nixos.org/download/) and [devenv 2.4.0](https://devenv.sh/getting-started/), then build in the development shell:

```sh
devenv shell
cargo build --release
```

The development shell supplies the pinned toolchain and Binaryen build tools; the first build compiles Binaryen from source. There is no installer archive in the repository's releases: build here and keep `target/release/i`.

## Compiler path

```sh
export PATH="$PWD/target/release:$PATH"
i --version
```

```text
i 0.1.0
```

Run this from the i source folder, or invoke `target/release/i` directly. That executable includes library modules, the formatter, and the language server. i is in development with no published release or package; its archive scripts produce local releases only.
