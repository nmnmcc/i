The language standard is the definition of i. Read its introduction for scope and qualifications, then use the numbered chapters for the rules of a topic. The compiler is still being developed and does not yet implement every rule in the standard.

The command line can show the standard's version:

```sh
i spec --version
```
```text
Version: 1.0; Date: 2026-11-14
```

Use `i spec --toc` for the table of contents, `i spec 2.1` for a numbered section and its subsections, or `i spec --search words` to find sections. `i spec --help` lists the options. The generated pages split the source standard at chapter headings; subsection anchors use the section number.
