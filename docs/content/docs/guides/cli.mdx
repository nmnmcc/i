Build a greeting command with typed arguments, help, and structured logging.

```toml file=i.toml title="i.toml"
name = "guide_cli"

[dependencies]
std = { path = "../std" }

[test]
collection = "std/test.tests"
```

```i file=src/options.i title="src/options.i"
(
	std/cli
	(Some) = std/option
)

(
	Options(..)
	parser
)

Options = (name = String, count = Int)
parser = () {
	cli.map2(cli.argument("name", "Name to greet", cli.text), cli.option(
		cli.Names(long = "count", short = Some("c")),
		"Number of greetings",
		cli.integer,
	), (name, count) { Options(name = name, count = count) })
}
```

```i file=src/main.i title="src/main.i"
(
	i/process
	i/stdio
	std/cli
	std/log
	(None) = std/option
	guide_cli/options
)

greet = (name, count) {
	{ count > 0 } |>
		(True) {
			stdio.print("hello " <> name)
			greet(name, count - 1)
		}
		| (False) { Nil }
}
main = () {
	{ process.args() == ["--help"] } |>
		(True) {
			usage = cli.help(options.parser(), "greet")
			stdio.write(<<usage:utf8>>)
			stdio.flush()
		}
		| (False) {
			cli.run(options.parser(), "greet", (opts) {
				{
					log.write(
						log.Entry(
							level = log.Info,
							message = "greeting",
							fields = [("name", opts.name)],
							at = None,
						),
					)
					greet(opts.name, opts.count)
				} <- (log.stdout())
			})
		}
}
```

```i test stdout=exact package=guide_cli title="test/options_test.i"
(
	i/fail
	testlib = (test) = std/test
	std/cli
	guide_cli/options
)

test("parses arguments", () {
	assert(
		cli.parse(options.parser(), ["Ada", "--count", "2"]) ==
			options.Options(name = "Ada", count = 2),
	)
	assert(
		cli.parse(options.parser(), ["Ada", "--count=2"]) ==
			options.Options(name = "Ada", count = 2),
	)
	assert(
		cli.parse(options.parser(), ["-c", "1", "--", "-name"]) ==
			options.Options(name = "-name", count = 1),
	)
	assert(
		fail.catch(() { cli.parse(options.parser(), ["Ada"]) }) ==
			Error(cli.MissingArgument(name = "--count")),
	)
	assert(
		fail.catch(() {
			cli.parse(options.parser(), ["Ada", "--count=bad"])
		}) ==
			Error(
				cli.InvalidArgument(
					index = 1,
					name = "--count",
					text = "bad",
					reason = "expected integer",
				),
			),
	)
	assert(
		cli.help(options.parser(), "greet") ==
			"Usage: greet\n  <name>\tName to greet\n  --count, -c VALUE\tNumber of greetings\n",
	)
})
```

```text
pass guide_cli/options_test.parses arguments
1 passed, 0 failed
```

Create `guide-cli/` beside `std/`; run commands there. `cli.parse` returns the parsed value or raises an error; `fail.catch` captures failures for assertions. Both `argument` and `option` require a value; error indexes start at zero, and an attached value belongs to its option's token.

```sh
i test --opt 0
i test --opt 2
```

```text
pass guide_cli/options_test.parses arguments
1 passed, 0 failed
```

Each command prints this result. Other builders include `flag` (Boolean), `optional` (`Option`), `many` (repeated options), and `rest` (remaining positionals); see `std/src/cli.i` and `std/test/cli_test.i`.

## Command entry

```sh
i run --opt 2 -- Ada --count=2
```

```text
info "greeting" "name"="Ada"
hello Ada
hello Ada
```

`process.args()` supplies tokens after the command's `--`, excluding the executable name; `cli.read` parses them and `cli.run` invokes its callback on success.

`at = None` omits the timestamp. `log.stderr()` selects standard error instead of the supplied stdout sink.

## Help

```sh
i run --opt 2 -- --help
```

```text
Usage: greet
  <name>	Name to greet
  --count, -c VALUE	Number of greetings
```

The parser reserves no help option: `main` handles exactly `["--help"]`. `cli.help` raises definition errors; its help string ends with a newline, so `stdio.write` avoids an extra line but needs flushing before exit. Help and successful actions exit with status 0.

## Parse failure

```sh
i run --opt 2 -- Ada
```

```text
MissingArgument("--count")
Usage: greet
  <name>	Name to greet
  --count, -c VALUE	Number of greetings

error: MissingArgument("--count")
guide_cli/main:17:1
```

Exit status is 1. `cli.run` writes the error and usage to standard error, then raises; the entry handler reports the uncaught error. Printed labelled errors omit their field labels.
