The library reference describes the modules in `std` and `i/…`. Select a module to find its exports and source documentation. The `i/…` modules are supplied with the compiler; `std` is a separate package.

To use `std` in a project, put its checkout path in `i.toml` under `[dependencies]`, as in `std = { path = "../std" }`; the path is relative to the package. For tests only, the starter project uses `[dev-dependencies]`. The generated reference pages take module introductions from `////` comments and export documentation from `///` comments. When a checked type is available, the generator includes it; otherwise it uses the source declaration.
