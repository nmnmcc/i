Find a function in its module reference and call it in your program.

```i run package=lookup title="src/main.i"
(
	i/core
	(Io) = i/io
	i/bool
)

main = () <- (io : Io) {
	io.print(
		core.inspect(bool.not(True)),
	)
}
```

```text
False
```

[bool](/docs/library/generated/std-bool) lists `not` among its exports; select an export for its declaration and source documentation.

## Text

```i run package=lookup title="src/main.i"
(
	i/core
	(Io) = i/io
	i/string
)

main = () <- (io : Io) {
	text = string.trim("  héllo  ")
	io.print(text)
	io.print(
		core.inspect(string.length(text)),
	)
	io.print(
		core.inspect(string.byte_size(text)),
	)
}
```

```text
héllo
5
6
```

[string](/docs/library/generated/std-string) documents index units and costs alongside its functions.

## Lists

```i run package=lookup title="src/main.i"
(
	i/core
	(Io) = i/io
	i/list
)

main = () <- (io : Io) {
	io.print(
		core.inspect(list.map([1, 2, 3], (n) { n * 2 })),
	)
}
```

```text
[2, 4, 6]
```

[list](/docs/library/generated/std-list) includes callback signatures.

## Parsed numbers

```i run package=lookup title="src/main.i"
(
	i/core
	i/fail
	(Io) = i/io
	i/int
)

main = () <- (io : Io) {
	io.print(
		core.inspect(int.parse("42")),
	)
	io.print(
		core.inspect(fail.catch(() { int.parse("oops") })),
	)
}
```

```text
42
Error(())
```

[int](/docs/library/generated/std-int) documents accepted input and the `Fail(())` service required for parsing.

## Dependencies

Add `std = { path = "../stdlib" }` under `[dependencies]` in `i.toml`; paths are package-relative. Test-only imports use `[dev-dependencies]`. Compiler-supplied `i/…` modules need no dependency.
