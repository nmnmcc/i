Find a function in its module reference and call it in your program.

```i run package=lookup title="src/main.i"
(
	i/core
	(Io) = i/io
	i/bool
)

main = () <- (io : Io) {
	io.print(
		core.inspect(bool.not(True)),
	)
}
```

```text
False
```

[bool](/docs/library/generated/i-bool) lists `not` among its exports; select an export for its declaration and source documentation.

## Text

```i run package=lookup title="src/main.i"
(
	i/core
	(Io) = i/io
	i/string
)

main = () <- (io : Io) {
	text = string.trim("  héllo  ")
	io.print(text)
	io.print(
		core.inspect(string.length(text)),
	)
	io.print(
		core.inspect(string.byte_size(text)),
	)
}
```

```text
héllo
5
6
```

[string](/docs/library/generated/i-string) documents index units and costs alongside its functions.

## Lists

```i run package=lookup title="src/main.i"
(
	i/core
	(Io) = i/io
	i/list
)

main = () <- (io : Io) {
	io.print(
		core.inspect(list.map([1, 2, 3], (n) { n * 2 })),
	)
}
```

```text
[2, 4, 6]
```

[list](/docs/library/generated/i-list) includes callback signatures.

## Parsed numbers

```i run package=lookup title="src/main.i"
(
	i/core
	i/fail
	(Io) = i/io
	i/int
)

main = () <- (io : Io) {
	io.print(
		core.inspect(int.parse("42")),
	)
	io.print(
		core.inspect(fail.catch(() { int.parse("oops") })),
	)
}
```

```text
42
Error(())
```

[int](/docs/library/generated/i-int) documents accepted input and the `Fail(())` service required for parsing.

## Dependencies

The standard library is the versioned package `i`: `i new` writes `i = "github.com/nmnmcc/i//stdlib@X.Y.Z"` under `[dependencies]` in `i.toml`, and source imports its modules as `i/…`. Nothing of the library is copied into a package; `i.lock` pins the version, `i update i` moves to the newest one, and `i publish` does not carry it. The dependency belongs under `[dependencies]` even when only the package's tests import the library. The source of every module, with the documentation shown here, is in `stdlib/src` of the repository.
