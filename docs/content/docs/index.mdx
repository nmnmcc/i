Start with a complete program, then follow the rules behind it. The [home page](/) connects the examples; these pages let you work through them in detail.

## Start here

- [Install i](/docs/getting-started/install), then [create your first program](/docs/getting-started/first-program).
- [Take the tour](/docs/tour) if you already know another programming language. Begin with [values and data](/docs/tour/values-and-data), then [functions and branches](/docs/tour/functions-and-branches).
- Continue to [services and errors](/docs/tour/services-and-errors), [structured tasks](/docs/tour/concurrency), and [macros](/docs/tour/macros) to follow their connections.

## Build something

Use the [guides](/docs/guides) for a concrete task: [a CLI](/docs/guides/cli), [files](/docs/guides/files), [an HTTP service](/docs/guides/http-service), [tests and test doubles](/docs/guides/testing), or [JS and WASI interop](/docs/guides/js-and-wasi-interop).

## Look up a rule or a function

- [Library reference](/docs/library): find a module and its source declarations.
- [The standard](/docs/standard): read the language definition, including [types](/docs/standard/generated/chapter-4) and [effects](/docs/standard/generated/chapter-9).
- [Contributing](/docs/contributing): work on the compiler, library, tests, or these pages. The [known-gap register](https://github.com/nmnmcc/i/blob/main/docs/design/spec-known-gaps.md) records differences between the current compiler and the standard.
