```i run package=hello env.PORT=8080 title="src/main.i"
(
	i/process
	i/fail
	i/stdio
	std/int
)

(
	read_port
	BadPort(..)
)
BadPort = ()
read_port = () {
	int.parse(process.env("PORT")) |>
		(Ok(port) ? port > 0 && port < 65536) { port }
		| (_) { fail.raise(BadPort) }
}
main = () {
	text = fail.catch(read_port) |>
		(Ok(port)) { "port " <> int.to_string(port) }
		| (Error(_)) { "invalid PORT" }
	stdio.print(text)
}
```

<h2>Matching and overloading, one construct</h2>
<p>One function handles several patterns and argument shapes; the same checked port flows through each call.</p>
<div className="slide-example">
```i test stdout=exact env.PORT=8080 project=examples/port package=hello title="test/format_test.i"
(
	testlib = (test) = std/test
	i/stdio
	std/int
	app = hello/main
)
format =
	(0) { "off" }
	| (port) { "port " <> int.to_string(port) }
	| (host, port) { host <> ":" <> int.to_string(port) }
test("matching and overloading", () {
	if = app.read_port()
	stdio.print(0 |> format)
	stdio.print(format(if))
	stdio.print(format("localhost", if))
})
```

```text
off
port 8080
localhost:8080
pass hello/format_test.matching and overloading
1 passed, 0 failed
```

<h2>A service is a value</h2>
<p>Supply an Environment value to the unchanged reader; the same code now reads only the test’s input.</p>
<div className="slide-example">
```i test stdout=exact project=examples/port package=hello title="test/main_test.i"
(
	testlib = (test) = std/test
	i/request
	i/process
	i/fail
	app = hello/main
)
read = (text) {
	fail.catch(app.read_port) <- (
		process.Environment(env = (_) { request.ready(Ok(text)) }),
	)
}
test("reads a port", () { assert(read("8080") == Ok(8080)) })
test("rejects a bad port", () {
	assert(read("oops") == Error(app.BadPort))
	assert(read("65536") == Error(app.BadPort))
})
```

```text
pass hello/main_test.reads a port
pass hello/main_test.rejects a bad port
2 passed, 0 failed
```

<h2>Concurrent calls keep their scope</h2>
<p>Both child calls finish before their results are printed, carrying the reader’s service and failure requirements.</p>
<div className="slide-example">
```i test stdout=exact env.PORT=8080 project=examples/port package=hello title="test/tasks_test.i"
(
	testlib = (test) = std/test
	i/task
	i/core
	i/stdio
	app = hello/main
)
test("joined reads", () {
	ports = task.both(app.read_port, app.read_port)
	stdio.print(core.inspect(ports))
})
```

```text
(8080, 8080)
pass hello/tasks_test.joined reads
1 passed, 0 failed
```

<h2>Generated code keeps the checks</h2>
<p>The typed macro doubles the checked port value; its arguments and expanded result must fit its signature.</p>
<div className="slide-example">
```i test stdout=exact env.PORT=8080 project=examples/port package=hello title="test/macros_test.i"
(
	testlib = (test) = std/test
	i/core
	i/stdio
	app = hello/main
	hello/macros
)
test("typed expansion", () {
	port = app.read_port()
	stdio.print(
		core.inspect(macros.twice(port)),
	)
})
```

16160

<h2>An error stays in the type</h2>
<p>A caller promising no service needs cannot leave BadPort unhandled; the checker rejects this call.</p>
<div className="slide-example">
```i error E0501 stderr=exact project=examples/port package=hello title="src/probe.i"
(
	app = hello/main
)

(
	pure
)
pure : () -> Int = () { app.read_port() }
```
