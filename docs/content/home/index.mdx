<div className="hero-example">
```i run package=hello env.PORT=8080 title="src/main.i"
(
	i/process
	i/fail
	i/stdio
	std/int
)

(
	read_port
	BadPort(..)
)
BadPort = ()
read_port = (name) {
	int.parse(process.env(name)) |>
		(Ok(port) ? port > 0 && port < 65536) { port }
		| (_) { fail.raise(BadPort) }
}
main = () {
	text = fail.catch(() { read_port("PORT") }) |>
		(Ok(port)) { "port " <> int.to_string(port) }
		| (Error(_)) { "invalid PORT" }
	stdio.print(text)
}
```

```text title="PORT=8080 i run"
port 8080
```

<h2>Simple enough</h2>
<p>Functions, data and a few symbols make a program.</p>
<div className="slide-example">
```i run package=hello title="src/main.i"
(
	i/stdio
	std/int
)
Num = (Int)
Add = (Expr, Expr)
Mul = (Expr, Expr)
Expr = Num | Add | Mul
eval =
	(Num(n)) { n }
	| (Add(a, b)) { eval(a) + eval(b) }
	| (Mul(a, b)) { eval(a) * eval(b) }
main = () {
	Mul(Add(Num(1), Num(5)), Num(7)) |> eval |> int.to_string |> stdio.print
}
```

```text title="i run"
42
```
</div>
</article>

<h2>Testable enough</h2>
<p>Hand a function a fake clock.</p>
<div className="slide-example">
```i test stdout=exact package=hello title="test/clock_test.i"
(
	testlib = (test) = std/test
)
Clock = (now = () -> Int)
elapsed = (start) <- (clock : Clock) { clock.now() - start }
test("a fake clock", () {
	assert(elapsed(40) == 2) <- (Clock(now = () { 42 }))
})
```

<h2>Extensible enough</h2>
<p>Write your own <code>if</code> when you need one.</p>
<div className="slide-example">
```scheme file=src/sugar.is title="src/sugar.is"
(, if)
(= _branches
  (-> (, then else) _ `(| (-> (, True) _ ~then) (-> (, False) _ ~else))))
(@ macro (= if (-> (, test then else) _ `(|> ~test ~(_branches then else)))))
```
