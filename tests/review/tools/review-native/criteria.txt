Pre-proposal criteria, recorded before reading docs/design/native.md.
Sources read: normative spec; accepted syntax; multicore (all 25 API rules); runtime R1/R2/IO contracts; host-concurrency ABI H1-H14 and R2 handoff; lazy-reentry control/environment invariants; relevant record and macro constraints. Accepted status follows the user's instructions where document headers lag.
1 Standalone: ordinary build/run supplies standard IO/runtime; no user Rust or JS required. Embedding and synchronous exported functions keep explicit supported behavior. Packaging is not a new language semantics.
2 Same sets of values/principal rank-one inference, no static Send, unsafe cast, keyword, or scheduler-only compiler hook. New language primitives need three unrelated uses; library algorithms remain ordinary i.
3 Some serial order of semantic steps explains every multicore run; copying/placement changes neither ==, hash, inspect, errors, nor local versus portable rules. Captures include source-defined captures and all kept services, including hidden record fields. Copy preserves sharing/cycles and constant identities.
4 go never rejects non-portable closure records; local tasks stay home; started tasks and requests never migrate. Top-level values equal across workers or use one worker.
5 New task boundary per task, one scheduler/root continuation per instance, kept services retained after repeated resumes and cancel. Nested runs use one worker, preserve prefix/root/owner affiliations and wait through the outer run.
6 Scope chains, run checks, path-order failure, cancel priority, protected finals, dropped-task joins, scope-owned channel/share lifetime, reusable CML events, one atomic commit, no self-rendezvous; callbacks in syncing task after unlock.
7 ABI v3 request IDs per instance, copies at start, no resume reentry, status 1 only with work, status 2/continue discipline, late replies discarded, host cleanup on faults, no i finals on stop.
8 IO handle abstraction needs nominal type/kind, identity/hash/inspect, no stale alias resurrection, operation leases, close and in-flight races, provisional/Ready/Taken resource ownership and run teardown; cross-worker uses access one shared resource.
9 Scheduling storage must separate local continuations/requests from portable data; no foreign Store GC refs; worker wakeups and deadlock detection must account for queued/claimed/running tasks, pending requests, cancellations and nested runs.
10 Wasmtime runtime-only deserialize requires compatible trusted artifacts and supported GC/runtime configuration; Store exclusivity is distinct from permanent thread affinity; establish shared-GC status in v50 source.
Hard cases: pinned go; recursive closures and shared DAG; width-hidden refs; equality across independent decodes; go vs cancellation/claim race; unstarted resource owner; mapped select losing branch/self pairing; join in shielded final; nested request roots and borrowed tickets; IO completion while other workers busy; closed/reused handles; duplicate top-level external effects; sync JS comparator export; foreign imports and target portability.
For four changes separately assess kept/lost/open guarantees, real R1/R2/IO redo if postponed, minimum contract needed now, alternative and falsifying evidence. Distinguish approved change from contradiction or missing mechanism. Report only concrete problems, not implementation details intentionally deferred.
