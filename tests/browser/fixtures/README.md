# Host ABI fixture

`host-abi.wat` is an independent test fixture for the JavaScript and Rust host
adapters. It is deliberately **not** an iLang compiler conformance fixture.

Regenerate the checked-in binary with `bash scripts/build-abi-fixture.sh` from a
Devenv shell containing wasm-tools 1.262.0. `WASM_TOOLS` can point at a specific
wasm-tools executable. The script validates the emitted module.

The fixture exercises WasmGC structures, typed function references, tail calls,
shared host imports, multivalue ABI returns and opaque `externref` round trips.
Every buffer round trip returns a separately allocated copy. The diagnostic
exports `live_allocations` and `live_bytes` let tests verify release of both the
input and returned allocation, including failures. Individual frees update
counters without reusing addresses; ABI frame resets restore the allocator's
cursor. This is test infrastructure, not the production allocator.

Both fixtures expose `__ilang_abi_mark() -> i32` and
`__ilang_abi_reset(token: i32)`. Mark returns a nonzero token and pushes a GC
frame holding the allocator cursor, allocation count and byte count. Reset
requires the most recent token and restores that snapshot. Out-of-order or
repeated resets trap without changing state. Frames support nested host calls
and consume no tracked linear-memory allocations. `active_frames() -> i32` and
`heap_end() -> i32` expose state for tests. Reset can reuse linear addresses but
does not shrink WebAssembly memory capacity.

`required-features.wat` is a dependency-free probe using a GC structure and a
typed tail call. Its `probe` export returns 42. The SDK embeds the generated bytes
to detect the required feature set without a network request.

`custom-imports.wat` exercises custom host function bindings. It imports
`echo_string`, `echo_int`, `echo_bits`, `echo_ref`, `echo_bool`, `echo_float`, and
`echo_nil` from module `custom`, and exports same-named forwarding wrappers. The
string, integer and bit-array imports return newly allocated buffers; host
wrappers call `__ilang_alloc` reentrantly to create these buffers. The outer caller
then frees both its original argument allocation and the returned allocation.
This module exports the same allocator, initialization and allocation counters
as `host-abi.wat`. Zero-byte allocations return nonzero pointers and must also be
freed, which makes empty-string, zero-integer and empty-bit-array ownership
observable. Neither fixture contains ABI metadata; tests supply descriptors.

The custom fixture also exports `leaking_throw(ptr, byte_length) ->
(ptr, byte_length)`. It allocates a guest temporary before calling `echo_string`
and frees that temporary on normal return. A host exception skips guest cleanup,
so tests can verify the outer ABI frame reset reclaims the abandoned allocation
while preserving the original exception.

The module has no start section. Hosts instantiate it, attach exported memory,
then call `__ilang_init` before invoking functions. Channels are supplied directly
to `emit`, so the fixture does not impose an output-channel convention.

| Export | Raw signature |
| --- | --- |
| `string_roundtrip` | `(ptr, byte_length) -> (ptr, byte_length)` |
| `int_roundtrip` | `(sign, ptr, limb_count) -> (sign, ptr, limb_count)` |
| `bit_array_roundtrip` | `(ptr, bit_length) -> (ptr, bit_length)` |
| `float_roundtrip` | `f64 -> f64` |
| `bool_roundtrip` | `i32 -> i32` |
| `nil_roundtrip` | `() -> ()` |
| `opaque_roundtrip` | `externref -> externref` |
| `reference_id` | `externref -> i64`, forwards to the host identity service |
| `emit` | `(channel, ptr, byte_length) -> ()` |
| `fill_random` | `(ptr, byte_length) -> i32` |
| `fail` | `(ptr, byte_length) -> trap` |
| `trap_with_string` | `(ptr, byte_length) -> trap` |
| `main` | `() -> ()`, writes `fixture main` plus a newline to channel 1 |
| `passing_test` | `() -> ()`, checks that initialization ran |
| `failing_test` | `() -> trap`, reports a host panic |
| `trapping_test` | `() -> trap`, traps without a host diagnostic |
| `fresh_instance_test` | `() -> ()`, fails if called twice in one instance |
| `feature_probe` | `() -> 42` using GC and a typed function reference |
| `tail_count` | `(n, accumulator) -> n + accumulator` using tail recursion |
| `gc_sum` | `n -> sum(1..n)` using short-lived GC structures |

Integer limbs are unsigned 32-bit words in little-endian order. Sign is -1, 0 or
1. Bit-array buffers contain `ceil(bit_length / 8)` bytes. The fixture intentionally
does not contain `ilang.abi` metadata, so tests supply explicit ABI descriptions.
